CSC 894: Healthcare AI Capstone

A graduate-level Computer Science capstone built around a real healthcare AI application deployed end-to-end on Google Cloud Platform. Students move through the full production arc — data ingestion, model training, deployment, and monitoring — with equity and clinical stewardship considerations embedded directly in the design rubric.

  • End-to-end GCP deployment: Cloud Run, BigQuery, Vertex AI, and IAM configuration
  • Clinical Stewardship Rubric with mandatory bias audit milestone at midterm
  • Real patient-outcome data with a de-identification pipeline built in the first sprint
  • Final deliverable: a deployed AI system with a live monitoring dashboard and model card

Ethics Framework

Clinical Stewardship & Design Equity Rubric

Developed as part of the CSC 894 capstone and informed by Engineering Leadership & Innovation Management training, this rubric operationalizes XAI ethics-by-design. It provides structured evaluation criteria for fairness audits, model explainability, and real-time pipeline oversight — translating abstract AI ethics principles into measurable engineering deliverables.

  • Explainability: SHAP-based feature attribution required at inference time for every model submission
  • Fairness audit: Demographic parity and equalized odds checks must pass before deployment milestone
  • Stewardship: Real-time monitoring hooks for distribution shift detection wired into the production pipeline
  • Transparency: Model card and data sheet required for every final submission
